# Re-hire Retired Agents Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Retired agents (agents/_retired/*.yaml) become visible in the Staff UI and restorable via a validate-and-move re-hire that enforces current hire rules (collisions, dept walls).

**Architecture:** Two pure builders in `src/web/agents-admin.ts` (`listRetired`, `validateRehire` — the latter reuses `validateHire` for all rules), two thin routes in `src/web/server.ts` mirroring the retire route's compensating-rename pattern, and a `RetiredSection` on the ui2 Staff view. The archived yaml is moved back byte-identical — never re-rendered.

**Tech Stack:** TypeScript, vitest, React (ui2), no new dependencies.

**Spec:** `docs/superpowers/specs/2026-07-21-rehire-design.md`

## Global Constraints

- No new npm dependencies.
- Trunk-based: commit on main, EXPLICIT file paths only in `git add` (parallel session shares checkout).
- Builders carry tests in root `test/`; route wiring stays thin and untested.
- Move, not re-render: the archived yaml is restored byte-identical via `renameSync`.
- Rehire error statuses: 404 absent archive file, 400 invalid/collision/wall (message from `validateHire` verbatim), 500 reload failure (after compensating rename back).
- **Route placement: `GET /api/agents/retired` MUST be matched BEFORE the `GET /api/agents/:name` profile route** — "retired" matches the profile route's name pattern.
- Read vitest's "Tests" summary line, not exit codes.
- Deploy: `npm run build && launchctl kickstart -k gui/501/com.ihab.aios`; ui2 touched → also `cd ui2 && npm run build` (then cd back).

```ts
/** Archived manifests in agents/_retired/ — one row per yaml; a bad file becomes {name, error}, never a throw. */
export function listRetired(archiveDir: string): Array<{ name: string; department?: string; kind?: string; title?: string; error?: string }> {
  if (!existsSync(archiveDir)) return [];
  return readdirSync(archiveDir).filter((f) => f.endsWith(".yaml")).map((f) => {
    const name = f.replace(/\.yaml$/, "");
    try {
      const m = agentSchema.parse(parseYaml(readFileSync(join(archiveDir, f), "utf8")));
      return { name: m.name, department: m.department, kind: m.kind, title: m.title };
    } catch (err) {
      return { name, error: (err as Error).message };
    }
  });
}

/** Rehire = validate-and-move. Reuses validateHire so collisions, dept existence, and dept walls
 *  apply to the archived manifest exactly as they would to a fresh hire. */
export function validateRehire(
  name: string, archiveDir: string, agentsDir: string, registry: LoadedRegistry,
): { ok: true; manifest: HireBody; from: string; to: string } | { ok: false; status: number; error: string } {
  const from = join(archiveDir, `${name}.yaml`);
  if (!existsSync(from)) return { ok: false, status: 404, error: `no retired agent "${name}"` };
  let m: ReturnType<typeof agentSchema.parse>;
  try {
    m = agentSchema.parse(parseYaml(readFileSync(from, "utf8")));
  } catch (err) {
    return { ok: false, status: 400, error: `archived manifest invalid: ${(err as Error).message}` };
  }
  const v = validateHire(
    { name: m.name, department: m.department, kind: m.kind as HireBody["kind"], title: m.title,
      charter: m.charter, persona: m.persona, prompt: m.prompt, capabilities: m.capabilities },
    registry,
  );
  if (!v.ok) return { ok: false, status: 400, error: v.error };
  return { ok: true, manifest: v.manifest, from, to: join(agentsDir, m.department, `${m.name}.yaml`) };
}
```

Note: if `agentSchema`'s manifest type makes any of these fields optional and tsc complains, coerce with `?? ""` for the string fields — but check the schema first; charter/persona/prompt/title are expected to be required.

```tsx
function RetiredSection() {
  const { data: retired, reload } = useFetch(() => api.retiredAgents(), []);
  const [error, setError] = useState("");
  const [busy, setBusy] = useState("");
  if (!retired?.length) return null;
  return (
    <section className={/* same section wrapper class as the packs list in this file */ ""}>
      <h3 className={/* same heading class as sibling sections */ ""}>Retired</h3>
      {error && <div className={/* same inline-error class HireForm uses */ ""}>{error}</div>}
      {retired.map((r) => (
        <div key={r.name} className={/* same row class as roster rows */ ""}>
          <span>{r.name}</span>
          <span>{r.error ? `unreadable: ${r.error}` : r.title ?? ""}</span>
          <span>{r.department ?? ""}</span>
          <button
            disabled={busy === r.name || !!r.error}
            onClick={() => {
              setBusy(r.name); setError("");
              api.rehireAgent(r.name)
                .then(() => reload())
                .catch((e: unknown) => setError(e instanceof Error ? e.message : String(e)))
                .finally(() => setBusy(""));
            }}
          >
            Rehire
          </button>
        </div>
      ))}
    </section>
  );
}
```

Render `<RetiredSection />` inside `Staff`'s org view output, after the department roster / HireForm area (the org list refreshes itself via its `useLiveQuery` on agent events after the daemon reloads packs — eventual consistency there is fine; `reload()` handles the retired list itself).
